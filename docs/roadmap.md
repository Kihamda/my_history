# 実装計画

最終更新：2026-08-14

コア機能は運用可能な段階にあります。
新機能の追加と並行して、安全性、データ整合性、検証基盤、配信手順を改善します。

## 実装済み

- Firebase Authentication による登録、ログイン、メール確認、再設定
- User プロフィールと招待受付設定
- ADMIN、EDIT、VIEW によるグループ権限
- スカウトの検索、作成、表示、更新、削除、グループ間移管
- スカウト単位の共有
- グループ設定、メンバー、招待の管理
- God モードによる三コレクションの管理
- ランディングページ、利用者ヘルプ、SPA の一体配信
- `dev` と `main` を分けた Cloudflare Workers デプロイ

## 安全性と権限

- [ ] 共有ロールの保存時検証と利用時検証を一致させる
- [ ] グループ情報の参照範囲と移管先確認の契約を分離する
- [ ] API のレート制限を導入する
- [ ] 権限変更、共有、移管、削除、管理者操作の監査記録を保存する
- [ ] God 権限の付与と失効に関する運用手順を定める

## データ整合性

- [ ] 一括更新の完了と失敗を応答前に確定する
- [ ] 所属、招待、共有の同時更新を原子的に処理する
- [ ] 削除後に残る関連参照を検出して整理する
- [ ] 名称キャッシュを更新処理と同期して無効化する

## API と検証

- [ ] 認証、認可、Scout CRUD、招待、共有、移管の自動テストを追加する
- [ ] ID、ページ、オフセットの入力検証を共通化する
- [ ] エラーレスポンスの構造、ステータスコード、表示言語を統一する
- [ ] API 契約を機械可読な形式で生成し、ルートと文書の差異を検出する

## ビルドと文書

- [ ] 公開ヘルプに含める Markdown を明示的に選択する
- [ ] Workers 配信用ディレクトリをビルドごとに初期化する
- [ ] Firebase Web 設定の環境分離方針を明文化する
- [ ] 文書リンクと主要な実装数値を CI で検証する

## 機能拡張

- [ ] CSV のインポートとエクスポート
- [ ] 分析とレポート
- [ ] PWA 対応
- [ ] 外部 API
- [ ] 複数団体を分離して扱う仕組み

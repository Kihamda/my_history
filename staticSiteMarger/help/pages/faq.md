# よくある質問

最終更新：2026-08-14

## ログイン後に利用を開始できません

メールアドレスの確認または初期プロフィールの保存が終わっていない可能性があります。
`/auth/verify` が表示された場合は確認メール、`/auth/setup` が表示された場合はプロフィール設定を完了してください。

## スカウトが見つかりません

選択中のグループ、検索条件、自分のロールを確認してください。
共有されたスカウトは、通常のグループ検索ではなくホームの共有一覧に表示されます。

## 編集できません

グループの VIEW は閲覧だけができます。
グループの ADMIN または EDIT が必要です。

共有されたスカウトは、共有が VIEW の場合は編集できません。

## 削除または移管ができません

削除と移管は、対象スカウトが所属するグループの ADMIN 専用です。
移管では、移管先グループの受け入れ設定も必要です。

## グループから脱退またはアカウントを削除できません

自分がグループで最後の ADMIN になっている可能性があります。
別のメンバーを ADMIN にしてから、もう一度操作してください。

## 問い合わせに必要な情報は何ですか

- 問題が起きた日時
- 操作していた画面
- 対象のスカウトまたはグループ
- 表示されたエラーメッセージ

パスワード、確認メールのリンク、認証トークンは送らないでください。

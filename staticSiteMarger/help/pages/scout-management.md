# スカウト情報の管理

最終更新：2026-08-14

## 検索

所属グループを選び、名前、登録番号、現在の隊で検索します。
名前は入力した文字から始まるスカウト、登録番号は完全に一致するスカウトを探します。

検索結果は 20 件単位です。
共有されたスカウトは、所属グループの検索ではなくホームの共有一覧から開きます。

## 作成

ADMIN または EDIT が、名前、9 桁以上 12 桁以下の登録番号、生年月日、所属グループを指定して作成します。
同じグループに同じ登録番号がある場合は作成できません。

## 表示と編集

所属グループのメンバーはスカウトを表示できます。
編集できるのは所属グループの ADMIN と EDIT、または編集権限付きで共有された利用者です。

編集画面では、個人情報、各部門の進歩と役務、技能章、行事を扱います。
保存するとレコード全体が更新されるため、同じスカウトを複数人で同時に編集しないでください。

## 削除と移管

削除と別グループへの移管は、現在の所属グループの ADMIN だけが実行できます。
移管先グループが受け入れを許可している場合だけ移管できます。

削除したデータは通常画面から復元できません。
対象と所属グループを確認してから実行してください。

# アカウントとログイン

最終更新：2026-08-14

## アカウント作成

メールアドレスとパスワードでアカウントを作成します。
確認メールのリンクを開くまで、記録データを扱う API は利用できません。

メール確認後は、次のプロフィールを設定します。

- 表示名
- ステータスメッセージ
- メールアドレス検索からのグループ招待を受け付けるか

招待受付を無効にすると、管理者がメールアドレスで利用者を探して新しい招待を送れません。
すでに所属しているグループや受信済みの招待は、この設定だけでは削除されません。

## ログインできない場合

パスワードを忘れた場合は、ログイン画面から再設定メールを送ります。
メール確認済みなのに進めない場合は、一度ログアウトしてから再ログインし、最新の認証状態を読み込んでください。

## アカウント削除

アカウント削除は User データを削除します。
自分がいずれかのグループで最後の ADMIN になっている場合は削除できないため、先に別の ADMIN を用意してください。

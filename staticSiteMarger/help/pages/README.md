# 利用者ヘルプ

最終更新：2026-08-14

このヘルプは、My History of Scouting を使う人向けの操作案内です。
開発者向けの API や保存形式ではなく、画面でできることと必要な権限を説明します。

- [権限と招待](./permissions-and-invites.md)
- [よくある質問](./faq.md)

## 主な機能

- 所属グループ内のスカウトを検索、表示、更新します。
- 進歩、技能章、役務、行事の履歴を記録します。
- グループの ADMIN がメンバーと招待を管理します。
- 特定のスカウトを、グループ外の利用者へ共有します。

操作できる範囲は、グループのロールまたはスカウト共有の権限によって変わります。

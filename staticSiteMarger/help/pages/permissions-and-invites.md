# 権限と招待

最終更新：2026-08-14

## グループロール

| ロール | できること |
| --- | --- |
| `VIEW` | 所属グループの検索とスカウト閲覧 |
| `EDIT` | VIEW の操作、スカウト作成と編集、共有管理 |
| `ADMIN` | EDIT の操作、削除、移管、グループ設定、メンバーと招待の管理 |

ADMIN は、自分自身をメンバーから削除したり、自分自身のロールを変更したりできません。
グループから脱退すると最後の ADMIN がいなくなる場合も、脱退できません。

## 招待

1. 利用者がプロフィールで招待受付を有効にします。
2. ADMIN がメールアドレスで利用者を検索します。
3. ADMIN がロールを選んで招待します。
4. 利用者がアカウント設定から受諾または拒否します。

同じグループへの招待を重ねて送ることはできません。
招待が見つからない場合は、招待受付設定と入力したメールアドレスを確認してください。

## スカウト共有

スカウト共有は、グループへの招待とは別です。
共有された利用者は、そのスカウトだけを閲覧できます。

新しい共有を作れるのは、対象スカウトの所属グループで ADMIN または EDIT の利用者です。
グループ設定で新しい共有を許可していない場合は作成できません。
